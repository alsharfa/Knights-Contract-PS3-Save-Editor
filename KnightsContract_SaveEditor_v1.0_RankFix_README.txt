Knights Contract PS3 Save Editor v1.0 — Rank Fix

WHY v0.9 DID NOT APPEAR TO WORK
===============================

1. The editor used internal difficulty names:
   EASY / NORMAL / HARD / VERYHARD / HELL

   The game uses:
   PAGE        = Easy
   SQUIRE      = Normal
   KNIGHT      = Hard
   HEXEN KNIGHT= Very Hard
   WITCHSLAYER = Hell

   The supplied screenshot is Episode 3 on HEXEN KNIGHT, which is result slot 3
   (the old editor called that VERYHARD). The old rank selector defaulted to
   HARD / slot 2, which is KNIGHT.

2. v0.9 changed only grade/rank fields. Episode Select also stores five displayed
   result-point fields, and leaving those at low values could leave the visible
   result inconsistent.
